# Запуск эксперимента

Откройте два терминала и подключитесь к базе данных в каждом из них:

```bash
docker exec -it typography_coursework_db \
  psql -U ilyasemenov -d typography
```

В первом сеансе запустите сценарий A:

```psql
\i /workspaces/practice-sem5/practice-04/src/session-a.sql
```

Когда выполнение остановится на первом приглашении, во втором сеансе
запустите сценарий B:

```psql
\i /workspaces/practice-sem5/practice-04/src/session-b.sql
```

Сценарии сами подскажут, когда переключаться между терминалами. После
получения результатов удалите тестовую строку:

```psql
\i /workspaces/practice-sem5/practice-04/src/cleanup.sql
```

Путь после `\i` должен соответствовать пути проекта внутри контейнера. Если
каталог проекта не смонтирован в контейнер, команды из SQL-файлов можно
вставить в соответствующие сеансы вручную.
