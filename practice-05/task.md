Задание по функциям и процедурам

Функция у всех одна - нужно найти в своей схеме базы данных поля ФИО или сделать если таковых нет

Написать функцию, которая из ФИО собирает инициалы - Лебедевич К.О. (пример)

Пример: вызвать эту функцию в селекте, передать туда 3 атрибута и следующая колонка - собранные имя (если отчества нет то двух точек подряд не должно быть)

Во вьюшке некоторое число аттрибутов
Написать процедуру вызвав которую во вьюшке появится новый аттрибут

В само вью вставлять ничего нельзя - выделить все связанные с нею таблички (уже выполнено), передать в эту функцию все значения (10-15 и мб больше аттрибутов) Затем согласовать ссылучную целостность

Пример: во вью попадает фио человека и число его записей, проверить что такой человек уже есть. Если его нет, нужно добавить. Если в записе например факт покупки, проверить, что она была. Если нет - добавить. Должны сработать все селекты ко вьюшке и получить результат. Проверить корректность (все добавилось или не добавилось когда уже есть)

Пример
Вью содержит: станцию, число сотрудников, число оборудования

Вызовом функции будет название станции, адрес, все данные в таблице станций, потом точно такой же кортеж для сотрудника, потом для оборудования (около 10 15 значений аттрибутов)

Потом написать прогу, которая проверяет, есть ли станция по айдишке. Если нет - добавить. Так же проверить сотрудника, есть ли он на станции, если нет - добавить на станцию. Потом оборудование по такому же принципу. Если нет - добавить на станцию

Для всех вариантов сделать правила. Мб понадобятся разные функции для назначения сотрудника и оборудования

Как триггеры, но реализуем процедурой с явным вызовом - весь код внутри процедуры. Для наглядности процедуры можно нарисовать блок схему, после переходить к коду. 

Еще раз на пальцах - процедура делает инсерт в таблицы которые влияют на вью, чтобы вью изменилась, внутри процедуры проверяется целостность.

Проверяем есть или нет уже добавленная запись, берем айди и проходимся по остальным влияющим таблицам. Если добавляем (не было), то фиксируем во вьюшке что что то поменялось
