\section{Постановка задачи}

Для выполнения работы используется база данных электронной типографии,
созданная в рамках курсовой работы. Цель работы~--- создать представление в
PostgreSQL и использовать его в нескольких запросах.

В ходе работы необходимо:

\begin{itemize}
    \item для каждого начертания определить число поддерживаемых форматов и
    градаций насыщенности;
    \item найти количество начертаний, поддерживающих больше $A$ форматов;
    \item найти пять категорий с наибольшим охватом форматов.
\end{itemize}

Охват категории равен сумме количества форматов всех входящих в неё
начертаний.
