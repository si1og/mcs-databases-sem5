\section{Постановка задачи}

Работа выполняется на базе данных предметной области <<Учёт компьютерных
шрифтов в электронной типографии>>, разработанной в рамках курсовой работы.
Цель практической работы~--- освоить создание представлений в PostgreSQL и
использование результатов предварительного агрегирования в последующих
запросах.

В ходе работы необходимо:

\begin{itemize}
    \item создать представление, которое для каждого начертания хранит число
    поддерживаемых форматов и количество градаций по насыщенности; при
    формировании представления должны использоваться две операции
    \mintinline{sql}{COUNT};
    \item проверить создание и содержимое представления;
    \item составить простой запрос к представлению с условием
    \mintinline{sql}{WHERE}, определяющий число начертаний, которые
    поддерживают больше $A$ форматов;
    \item составить запрос с соединениями таблиц, который находит первые пять
    категорий по суммарному охвату поддерживаемых форматов.
\end{itemize}

Под охватом форматов категории понимается сумма количеств форматов,
поддерживаемых каждым начертанием данной категории. Если два начертания
поддерживают один формат, обе поддержки учитываются в охвате.
